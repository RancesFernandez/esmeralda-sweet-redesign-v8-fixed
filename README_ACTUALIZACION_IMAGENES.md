# Esmeralda Sweet — actualización de imágenes

Este paquete contiene las **29 imágenes nuevas detectadas** en el proyecto y los tres archivos de datos actualizados para que queden integradas en el catálogo.

## Cómo instalar

Copiá/sobrescribí el contenido de este ZIP sobre la carpeta raíz de tu proyecto:

- `src/assets/images/productos/` → contiene las 29 fotos nuevas.
- `src/data/imagenes.js` → registra e importa todas las fotos nuevas.
- `src/data/productos.js` → incorpora las fotos al catálogo y agrega las propuestas correspondientes para alfajores, muffins, rolls de canela y las nuevas variantes de desayunos.
- `src/data/menuCategorias.js` → actualiza las imágenes de las tarjetas de categorías para usar las nuevas fotos.

No incluye `.git`, `node_modules` ni el resto del proyecto, para que puedas sustituir únicamente los archivos necesarios.

## Imágenes nuevas detectadas

Alfajores (4), tortas/postres (5), desayunos (8), muffins (2), picadas (2), rolls de canela (2) y tortas personalizadas (6).
